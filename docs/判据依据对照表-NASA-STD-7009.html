我们的六条规则，对应 NASA 标准里哪一条

用途：回答「你们的判据是拍脑袋定的吗」
依据：NASA-STD-7009《Standard for Models and Simulations》及其 B 版（2024-03-05，88 页）
结论：六条规则不是自创判据，而是把标准中「Verification」这一项的要求自动化了
一句话结论（答辩可直接用）
NASA-STD-7009 定义 Verification 因子的原话是：
「Were the models implemented correctly, and what is the numerical error/uncertainty?」
——正好是两件事：① 实现对不对 ② 数值误差是多少。 我们的六条规则，做的就是这两件事的自动判定。

而标准只回答了「应该评估什么」，没有回答「怎么自动评估」——实施仍依赖专家人工。我们填的是这个空。

★ 一个容易被混淆的点：我们做的是 Verification，不是 Validation
标准里的 Verification（实现对不对、数值误差多少）与 Validation（像不像真实世界）是两件不同的事。
我们做的全部是前者——对照解析解属于 Code Verification 的范畴（比的是数学真值，不是实验数据）。
我们不声称做过 Validation，因为本内核不含 J2 摄动等真实力模型，与真实轨道的差异是已知且刻意保留的。

「第 3 级」这个定位的分量
标准对 Level 3 的要求是「形式化数值误差估计」。
关键词是「形式化」——不是「跑几组试试看」，而是有可复现的估计方法。我们给出的是 E(h) ≈ A·hᵖ 的标定式（含 A、p 与拟合优度），并做四重可靠性检验（R² / 残差 / 外推 / 幂次自洽）， 不通过就返回「不可用」而不是返回数字。

三逐条规则的出处

表 4　六条规则各自的 NASA 依据
规则我们检查什么对应标准里的什么
R2 用四点阶梯实测收敛阶，明显低于理论阶即报警 Code Verification 的教科书手段。标准把 order-of-accuracy testing 明确列为 Code Verification 的核心方法—— 因为「实现写错了」最典型的表现就是收敛阶对不上
R1 守恒量达标、但位置误差超差 → 致命级 Verification 同时要求「实现对不对」和「数值误差多少」。两个指标互相矛盾时，说明至少有一个不能用—— 这是把领域已知陷阱（守恒量好≠位置准）形式化
R3 步长已到浮点地板，再细化无改善 Solution Verification 的下界刻画。标准要求给出数值误差；误差到不了零，卡在什么上就必须说清—— 我们的答案是双判据：标定式反推 + 现场再细分 8 倍实测
R4 递推发散（迭代跑飞） Verification 的底线：结果不可用时必须明说。标准 Level 0 =「Insufficient evidence」，发散即落此档
R5 短弧段合格、长弧段不合格 对应 Results Robustness（⑤）——结论的适用范围。标准问「敏感性掌握到什么程度」， 我们问的是「这个结论在外推到更长弧段时还成立吗」（同构的问题）
R6 两项指标均不达标 综合判定：该配置不合格。对应 Verification 因子的低分档

四我们没做的，以及为什么

表 5　主动列出边界（答辩时先说自己说，比被问出来好）
项状态与理由
Validation 不做。内核只有二体引力，不含 J2／大气阻力／三体摄动——与真实轨道的差异是已知且刻意保留的 （加摄动会让解析真值失效，而解析真值是全部可信度主张的地基）。不声称"验证了模型像真实世界"。
概率型 UQ 不做。我们是确定性误差分解（截断／浮点／参考解），不改参数分布、不做蒙特卡洛。 这属于标准的 ④⑤ 两类，不是我们这条线的重点。
Verification Level 4 不声称。Level 4 要求「所有重要特征的误差都小」，而「小不小」取决于用途和阈值。 我们的工具反推「要达到你给的阈值需要多少步」，但不替用户宣布"够好了"。
标准中的 ⑥⑦⑧
Use History / 管理 / 人员资质		 不在工具职责内。那是项目层评估，属于工程管理体系，不是软件能自动完成的

五答辩话术（可直接照用）

被问「你们的判据是不是自己想的？」
「不是。我们的六条规则对应 NASA-STD-7009 的 Verification 因子。

标准对这个因子的要求原话是「实现是否正确、数值误差是多少」——正好是我们做的事。 其中 R2 的观察阶测试，是标准明确列出的 Code Verification 核心手段；R3 的浮点下界是 Solution Verification 的下界刻画。

标准给 Verification 打了 0–4 级，Level 3 是「形式化的数值误差估计」，我们在这一级—— 因为我们给出的是带拟合优度和四重检验的误差标定式，不是「跑几组看看」。

标准回答的是「应该评估什么」，没回答「怎么自动评估」。我们填的是这个空。」
被追一句「那你们为什么没到 Level 4，也没做 Validation？」
「这两条都是我们刻意划的边界。

不到 Level 4：Level 4 要断言「所有重要特征的误差都小」，但「小」取决于用途和阈值。 我们反推「要达到你给的精度需要多少步」，但不替你宣布够好了——判定权应该在提出需求的人手里。

不做 Validation：内核只有二体引力，与真实轨道的差异是已知且刻意的。加了摄动，解析真值就没了，而 解析真值是全部可信度主张的地基。所以我们做窄而深，不声称验证了"像真实世界"。」
