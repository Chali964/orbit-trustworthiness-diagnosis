结论先行（三条）
  1. 短的弧段用 RK4。相同精度下，它需要的步数比二阶方法少约 两个数量级—— 粗估级精度下 RK4 只要 165 步，二阶方法要 1.3–2.4 万步。
  2. 长弧段（几百圈以上）用辛积分器。它的能量误差是有界振荡而非单调漂移，跨弧段不会累积。
  3. 不要用前向欧拉。它是唯一的一阶方法，而且对二体问题条件不稳定——误差不服从幂律， 工具会直接判定"不可预测"并拒绝给步数。

★ 从表里能直接读出的两个规律
① 四阶的威力是实打实的。看 RK4 那一列：精度提高 10⁴ 倍（1e-6 → 1e-10）， 步数只从 165 增到 1423，约 8.6 倍——与理论关系"步数 ∝ 精度−1/4"吻合（10⁴ 的四次方根是 10）。

② 二阶方法在高精度下不可行。同样是 1e-10 精度，RK4 要 1 千多步， 二阶方法要一百万步以上——算力差三个数量级。

三怎么选：四步决策

  1. 先问「弧段有多长」。
    只算几圈以内 → 走下一步；
    要算几百圈以上 → 直接用辛积分器。理由是它的能量误差有界振荡， 跨弧段不累积；四阶方法虽然单圈更省，但长期会单调漂移。
  2. 再问「精度要求多高」。
    常规工程精度 → RK4（相同精度下步数最少）；
    只要粗估 → 中点法（改进欧拉在同精度下要多花约一倍步数，见上表）。
  3. 排除前向欧拉。它是唯一的一阶方法，且对二体问题条件不稳定—— 误差随时间指数增长、不服从幂律。工具会判定"不可预测"并拒绝给步数。 这不是工具不够聪明，是正确行为：宁可说不可用，也不返回基于假假设的数字。
  4. 最后仍要用工具验一遍。上表是经验排序，真正该用多少步要针对你的具体配置现场标定—— 同一种方法在近地圆轨道与极端偏心椭圆上，所需步数能差一个数量级以上。

四两个必须知道的陷阱

陷阱一：辛积分器要用「位置」口径标定，不能用守恒量
对 RK4、改进欧拉、中点法，用守恒量口径标定拟合优度更高。
但对辛积分器必须改用位置口径——因为它的能量误差是有界振荡， 末值受相位影响，硬拟合成幂律会得到假的幂次；而位置误差是相位累积，服从干净的幂律。

实测：leapfrog 位置口径 p = 1.999 / R² = 1.00000（干净）； 守恒量口径 p = 5.359 / R² = 0.97694（明显不可靠）。

本工具的 calibrate_step 会自动按拟合优度选择口径，使用者不需要判断—— 但如果是手工算，这个坑必须知道。
陷阱二：极端偏心率下，"需要多少步"可能无解
看表 2–4 的最后一行：极端偏心率椭圆（a=70000 km，e=0.9）一栏全是"不可预测"。

原因不是工具不会算，而是这个场景下误差不再服从幂律： 近地点速度高达 10.4 km/s，误差由近地点通过那一小段主导， 误差随步长的变化不再是干净的幂次关系。

此时任何"需要 X 步"的建议都是编的，所以工具拒绝给数。 这恰好呼应本项目的设计原则：说不清的地方，就说说不清。

五为什么表里有很多空格（这是设计，不是缺陷）

第一次看到这几张表，容易觉得"怎么这么多"—"和"不可预测"，是不是工具不行。

恰好相反。这些空格代表三种不同的"我不能骗你"：

如果这些地方填上数字，表格会"好看"很多，但那些数字都是假的。 本项目的设计取向是：宁可留空，也不返回基于假假设的数字—— 因为工具输出会被使用者和智能体直接采信，而假数字不会自己报警。
