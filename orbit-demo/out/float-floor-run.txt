步骤 3　标定截断误差项　E ≈ A·h^p
  拟合用点：n = 50, 100, 200, 400, 800, 1600（全部落在截断主导区）
  比能量误差：p = 4.9984，C = exp(截距) = 3.680565e+03
             A = C / T^p = 5.548614e-16 s^-p   （换算方向：除以 T^p）
  位置误差　：p = 4.2670，A = 1.703057e-09 s^-p
  反算校验（比能量）：
     n=50      A·h^5.00 = 1.1852e-05    实测 = 1.1892e-05    相对偏差 -0.3%
     n=100     A·h^5.00 = 3.7079e-07    实测 = 3.7074e-07    相对偏差 +0.0%
     n=200     A·h^5.00 = 1.1600e-08    实测 = 1.1579e-08    相对偏差 +0.2%
     n=400     A·h^5.00 = 3.6291e-10    实测 = 3.6179e-10    相对偏差 +0.3%
     n=800     A·h^5.00 = 1.1354e-11    实测 = 1.1304e-11    相对偏差 +0.4%
     n=1600    A·h^5.00 = 3.5520e-13    实测 = 3.5737e-13    相对偏差 -0.6%

步骤 5　平台高度与转折步长
  比能量：平台 = 1.4100e-14（= 63.5 × ε），样本散布 7.36e-15 ~ 3.16e-14（4.3 倍）
          令 A·h^p = 平台  →  h = (平台/A)^(1/p) = 1.9103 s  →  每圈 3051 步
  位置量：平台 = 1.2229e-09 km，样本散布 2.21e-10 ~ 7.31e-09（33.1 倍）
          转折步长 = 0.9253 s  →  每圈 6299 步
  → 工程含义：每圈步数超过上述转折值后，再缩步长只是白烧计算量。

  交叉核对（重要）：模型转折点 vs 实测平台起点
    指标           模型转折(步/圈)        实测起点(步/圈)       
    比能量          3051             3200            
    位置量          6299             12800           
    比能量两法基本一致（差 5%）；位置量实测起点明显偏大。
    原因：平台是随机分布，偶尔抽到比中位数低一个数量级的点，
          会让「翻倍还有效」的判据误判为仍在截断区（n=12800 就是这种幸运样本）。
    因此工程上应以「模型转折点」设阈值，「实测起点」只作旁证，不能单独当依据。

步骤 6　复现性检验：同一步长，只改初始相位 t0，误差是否复现？
        这是「舍入区能否拟合出幂律」的判决性实验。
  初始相位 t0(s)     每圈步数         位置误差(km)           比能量相对误差           
  ------------------------------------------------------------------------------
  0.000          400          1.4183e-04         3.6179e-10        
  728.565        400          1.4154e-04         3.6179e-10        
  1457.129       400          1.4973e-04         3.6180e-10        
  2185.694       400          1.6194e-04         3.6179e-10        
  2914.258       400          1.6883e-04         3.6179e-10        
    散布倍数                      1.19 倍             1.00 倍            
  ------------------------------------------------------------------------------
  0.000          51200        2.6632e-09         2.0464e-14        
  728.565        51200        1.2412e-10         4.7417e-15        
  1457.129       51200        1.6486e-09         1.4225e-14        
  2185.694       51200        1.1259e-09         1.6471e-14        
  2914.258       51200        8.8079e-10         6.4886e-15        
    散布倍数                      21.46 倍            4.32 倍            
  ------------------------------------------------------------------------------
  结论：截断主导区（n=400）改相位，误差几乎不变，说明它是确定的、可拟合的；
        舍入主导区（n=51200）改相位，误差变动数倍，说明它是随机的、不可拟合的。
        → 所以「下界」只能按分布（中位数 + 散布范围）刻画，不能按曲线刻画。

步骤 7　平台会随积分时长抬高吗？（固定每圈步数 51200，只改积分圈数）
  积分圈数       总步数            位置误差(km)           比能量相对误差           
  ------------------------------------------------------------------
  1          51200          1.3359e-09         3.5812e-14        
  2          102400         2.6632e-09         2.0464e-14        
  4          204800         7.9886e-09         5.4155e-14        
  8          409600         1.8374e-08         7.1500e-14        
  ------------------------------------------------------------------
  幂次拟合（误差 ∝ 圈数^q）：比能量 q = 0.440，位置量 q = 1.293
  参考：若舍入误差互不相关、按随机游走累积，应得到 q ≈ 0.5；若完全同向累积，q ≈ 1。
  → 结论：平台不是常数，积分越长平台越高。所以「下界」必须连同积分时长一起报，
          否则同一套参数换一个积分弧段就会得出不同的下界。

步骤 8　汇总：可直接写进检查清单的量化指标
  ── 标定式（确定性）
     比能量相对误差：E(h) ≈ 5.5486e-16 × h^5.00
     位置误差：      E(h) ≈ 1.7031e-09 × h^4.27  (km)
  ── 精度平台（随机，给分布）
     比能量：中位数 1.410e-14（64 ε），散布 7.36e-15 ~ 3.16e-14
     位置量：中位数 1.223e-09 km，散布 2.21e-10 ~ 7.31e-09
  ── 转折步长（本场景，2 圈）
     比能量口径：1.910 s / 每圈 3051 步
     位置量口径：0.925 s / 每圈 6299 步
  ── 可用步数区间
     给定目标精度 E_target（比能量口径，且 E_target ≥ 1.410e-14）：
       n_required = T·(A/E_target)^(1/p)
         E_target=1e-09  →  至少每圈 327 步
         E_target=1e-11  →  至少每圈 821 步
         E_target=1e-13  →  至少每圈 2062 步
     上界：每圈 3051 步（超过即无效）
     因此 n ∈ [n_required, 3051]，且 E_target 不能低于 1.410e-14。
